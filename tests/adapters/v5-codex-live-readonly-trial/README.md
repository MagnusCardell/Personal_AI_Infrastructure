# V5-S13A Clean-Clone Read-Only Trial

S13A is a clean-clone read-only trial only. The trial source is the current repository working tree and the approved repository-local roots listed in the S13A contract.

S13A is not an existing-local-v5 trial. S13A is not a personal-clone trial. It does not inspect `~/.claude/PAI`, does not inspect `~/.claude/projects`, does not inspect `~/.codex`, and does not inspect arbitrary home directories.

S13A does not run Codex. S13A does not run Claude Code. S13A does not start Pulse. S13A does not call Pulse endpoints.

S13A does not write PAI Memory or ISA. S13A does not read or promote product memories.

The consent artifact, preflight report, and clean-clone evidence report are non-canonical adapter-test artifacts only. They are not PAI Memory, not ISA, not Pulse state, not Claude memory, not Codex memory, not a manifest, not runtime payload, and not proof that Codex is drop-in.

Codex is not currently proven drop-in for existing local PAI v5 files.
